🚀 HOW IT WORKS (The Complete Flow):

  STEP 1: Open Browser
          └─ Selenium opens Chrome browser
          └─ Navigates to Facebook URL

  STEP 2: Scroll Loop
          └─ Scroll down 500px (configurable)
          └─ Wait 3 seconds (configurable)
          └─ Parse HTML with BeautifulSoup
          └─ Extract posts and keywords
          └─ Check stop conditions
          └─ Repeat...

  STEP 3: Stop Conditions (Any ONE triggers stop):
          • Page height unchanged = No new content
          • Highlighted text found = Target reached
          • Max scrolls reached = Limit hit

  STEP 4: Export Results
          └─ Get all collected posts
          └─ Export to CSV file
          └─ Cleanup and close browser

════════════════════════════════════════════════════════════════════════════════

⚙️  CONFIGURATION SETTINGS (src/config.py):

  Scroll Settings:
    MAX_SCROLLS = 10              # How many times to scroll
    SCROLL_PAUSE_TIME = 3         # Wait after each scroll (seconds)
    SCROLL_DISTANCE = 500         # Pixels to scroll each time

  Browser Settings:
    SELENIUM_HEADLESS = False     # Show browser window
    SELENIUM_TIMEOUT = 10         # Page load timeout
    BROWSER_WINDOW_WIDTH = 1920   # Browser size
    BROWSER_WINDOW_HEIGHT = 1080

  Performance:
    DISABLE_IMAGES = True         # Faster loading

🔧 TROUBLESHOOTING:

  Chrome driver not found?
  → pip install webdriver-manager

  Page load timeout?
  → Increase SELENIUM_TIMEOUT in config.py

  No posts found?
  → Disable SELENIUM_HEADLESS to see browser
  → Increase SCROLL_PAUSE_TIME

  Too slow?
  → Set DISABLE_IMAGES = True
  → Reduce SCROLL_PAUSE_TIME
  → Enable SELENIUM_HEADLESS

════════════════════════════════════════════════════════════════════════════════

📋 STOP CONDITIONS EXPLAINED:

  1. NO NEW CONTENT LOADS
     └─ After scroll, page height unchanged
     └─ Indicates end of feed
     └─ → Stop scrolling

  2. HIGHLIGHTED TEXT FOUND
     └─ Post contains keyword from SEARCH_KEYWORDS
     └─ Target content reached
     └─ → Stop scrolling

  3. MAX SCROLLS REACHED
     └─ Number of scrolls >= MAX_SCROLLS
     └─ Prevents infinite scrolling
     └─ → Stop scrolling
